# Uploading this review to Anonymous GitHub

1. Create a GitHub repository and copy the **contents of this directory** to its root.
2. Do not commit `LIBERO_EX_ANONYMOUS_REVIEW.zip`; Anonymous GitHub does not support files larger than 8 MB.
3. Enable GitHub Pages from the repository root on the branch you intend to anonymize.
4. Visit <https://anonymous.4open.science/>, sign in with GitHub, choose **Anonymize**, and paste the repository URL.
5. Select the same branch/commit, keep images and links enabled, enable GitHub Pages, configure redaction terms and expiration, and create the mirror.
6. Share the generated anonymous repository URL or its **View Page** URL.

The generated review tree contains no local absolute paths, and every individual file is below 8,000,000 bytes. Binary images and videos should still be manually checked because Anonymous GitHub serves binary files as-is.
