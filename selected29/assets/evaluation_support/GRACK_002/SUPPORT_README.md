It adds only an invisible actual-upper-deck site in memory; original assets and legacy site behavior stay unchanged. Replay `FIXTURE_REPLAY.json` and the exact five `task.pruned_init` states. Use `RackPlacementProbe` and `RackPlacementObserver` after every actual control endpoint: annotated On, actual upper-face positive force, root over/above deck, no gripper contact, five consecutive controls. These files are frozen source/provenance, not a standalone portable policy package. They require the existing LIBERO/robosuite environment, asset tree and the original RAIN evaluator dependencies recorded in `run_config.json`.
