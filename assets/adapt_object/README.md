# Adapt Object public artifacts

The exact exhaustive task space is 10 original LIBERO-Object scenes × 5 non-original targets. All 50 definitions retain the original physical layout and pruned init states. Five original evaluation episodes were audited per task.

- `RESULTS_KO.md`: evaluation summary and successful-task table
- `AUDIT.json`: source hashes and protocol validation
- `episode_outcomes.tsv`: all 250 binary outcomes
- `task_bundles/` and `task_bundles.zip`: complete runnable definitions
- `comparison_png/`: source/new-target comparisons
- `success_reels/`: original successful episodes concatenated by task
