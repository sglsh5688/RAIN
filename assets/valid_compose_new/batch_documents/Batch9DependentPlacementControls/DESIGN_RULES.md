# Batch 9 design rules

- Same-drawer insertion/close tasks test dependent composition with exact successful insertion donors.
- Other tasks extend stove, cabinet-top, or plate placement with a drawer or knob control.
- Object and fixture poses are donor-exact; only task-required drawer openings are changed.
- Turn-on masks only the stove knob.
- Every sequence is novel against indexed prior tasks; strict native order and final BDDL apply without a final TC gate.
