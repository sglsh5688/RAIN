The destination input now uses the original native microwave main BODY mask, instead of an interior-floor-only mask. This is placement only, with the door kept open. Door closing is forbidden, not merely optional. Instruction, scene, initial states, policy masks and checkpoints are not changed by this scoring correction.

Corrected rule for future instrumented evaluations

Start with the door open. Record microwave_1_microjoint at every actual control step. A native Close event permanently fails the episode, even if the door is reopened. Success requires native Open together with native In, full collision-envelope containment, exact floor support and no gripper contact for five consecutive control steps. Native Open is qpos < -1.3 rad; native Close is qpos > -0.005 rad. They are separate predicates; the interval between them is neither open nor closed. This guard has not been used to run a new five-episode trial here.
